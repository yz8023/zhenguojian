# 真果鉴（Zhenguojian）

本仓库用于发布「真果鉴」Android 应用的构建产物（APK），供应用内更新检查使用。

本项目基于以下开源项目构建，**版权归原作者所有**：

本仓库仅用于存放针对个人设备（极米 Z8X 投影仪）重新构建的安装包，未对原项目主张任何权利。
如有侵权，请联系删除。

## 构建版本说明

原项目有两套编译版本（编译期决定，应用内无法切换）：

| 构建参数 | 应用名 | 站源 |
|---|---|---|
| 默认 | 红果鉴 | 仅红果 |
| `--all-sources` | **真果鉴** | 红果、黄豆、黄剧、黄果视频、黄果 AI、黄果旧版 |

本仓库发布的为 **真果鉴（全站源）** 版本。

## 下载

请前往 [Releases](https://github.com/kuoluoss/zhenguojian/releases) 页面下载最新 APK。

## 安装说明

- 目标架构：`arm64-v8a`（64 位 ARM，适配极米 Z8X 等设备）。
- 最低系统：Android 8.0（API 26）。
- 包名：`com.duanju.duanju_app`，可直接覆盖安装旧版本，无需卸载。
- 仅提供 Android 手机版（TV / 电脑版代码保留，暂停适配与验证）。

## 源码

本仓库同时提供业务源码，供查阅与自行构建。**只提交业务源码**，以下内容属于本机 / 隐私信息，一律不上传：

- 构建产物：`build/`、`dist/`、`*.apk`、`*.zip`；
- 依赖与缓存：`.dart_tool/`、`android/.gradle/`、`android/build/`、`windows/flutter/ephemeral/`、`ios/Pods/`；
- 本地环境与机器配置：`android/local.properties`、IDE 配置；
- 签名与凭据：`*.jks`、`*.keystore`、`key.properties`，以及任何 Token / 密钥 / 账号信息；
- 原生预编译产物：`android/app/src/main/jniLibs/` 下的 `.so`。

**最新源码版本：`0.6.1+49`（2026-10-13）。** 本版为播放器布局微调：
- **播放键与时间移到进度条左侧**：暂停/播放键与「当前时间 / 总时长」不再单独占一行，
  改到进度条左边，与右侧的全屏按钮左右对称，底部少了一层。
- **清晰度、追剧放回底部常显**：底部直接可见：倍速、清晰度、选集、追剧、连播。
- **移除「更多」按钮**：功能都放回外面后它已无内容可放，暂时去掉。
- **全屏界面同步改版**：与竖屏保持同一套按钮和顺序。

历史版本说明：
- `0.6.0+48`（2026-10-13）：播放器界面重设计 + 能力补齐——**只保留剧名一行**，
  简介/热度/集数/详情移出播放界面；底部精简为 4 个按钮（倍速/选集/连播/更多），
  清晰度与追剧收进「更多」面板；**全屏按钮移到进度条右侧**（纯图标）；
  全屏界面同步改版；连播按钮加颜色区分（本剧=主题色）；
  补齐**播放自动恢复**与**本地媒体播放**两项能力。
- `0.5.1+47`（2026-10-13）：**彻底修复开启 VPN 时检测不到更新**——改用**不占用 GitHub API 额度**的
  「重定向法」作为首选（读 `releases/latest` 的 302 得到版本号，再解析附件名），API 仅作兜底。
  此前失败有两个原因：① GitHub API 对**共享 VPN 出口 IP 限流**（返回 403）；
  ② 原兜底镜像 `ghfast.top` **不支持 API**（返回 403 `Invalid input.`），从未生效。
  现在兜底改为可用的 `gh-proxy.com`，并在被限流时给出明确提示。
- `0.5.0+46`（2026-10-13）：**修复开启 VPN 时检测不到更新**（走系统代理并注入 `HttpClient.findProxy`）；
  **弱网播放优化**（关闭磁盘缓存改用内存缓存、加大流层缓冲，缓冲吃紧时暂停预载）。
- `0.4.0+45`（2026-10-12）：**移除弹幕功能**（按用户要求，后续不再增加和使用），删除了弹幕控制器、
  弹幕滚动显示层、弹幕数据模型、表情对照表、原生弹幕接口与解析，以及全部弹幕测试；
  播放器、竖滑播放器、全屏层与电视播放设置中的弹幕开关、状态和重试入口一并移除。
- `0.3.7+44` 是**最后一个含弹幕的版本**。

> 因为不含预编译原生库，克隆源码后**不能直接构建出可用的安装包**，需要先用 Go 工具链编译 `native/core` 生成 `libduanju_core.so`。

构建命令（必须在**纯英文路径**下执行，中文路径会导致构建失败）：

```powershell
py scripts\build_android.py --abi arm64-v8a --all-sources
```
